Project Site Plan

Stage Lighting & Concert Production

Developer: Victor Eduardo Sanabria Diaz

1. Site Name

Site Name: Apex Stage & Concert Tech

Reasoning: This name represents a modern platform focused on professional concert production, event technology, and stage lighting design.

Optional Domain Availability: apex-stage-tech.org

2. Site Purpose

The website serves as an informational hub for live event setup, concert production technology, and modern stage lighting design. It provides educational resources, equipment guides (such as LED bars and controllers), and consultation request options for event organizers and aspiring technicians.

3. Target Audience Scenarios

Visitors to the site will typically look to answer the following questions:

  • What type of stage lighting equipment is best suited for small indoor concert venues?
  • Where can I find technical specifications and setup guides for DMX controllers?
  • How do I request a professional lighting design consultation for an upcoming live event?

4. Color Scheme

The chosen color palette reflects a professional concert atmosphere (dark stage tones paired with vibrant stage lighting accents):

  • Primary Color (#0f172a - Dark Slate / Stage Black): Used for headers, primary backgrounds, and major containers.
  • Secondary Color (#f59e0b - Amber / Stage Spotlight): Used for headings, borders, and call-to-action highlights.
  • Accent Color (#38bdf8 - Electric Cyan): Used for interactive elements and subtle highlights.

5. Typography

The project utilizes two clean, modern Google Fonts to ensure readability and aesthetic appeal:

  • Heading Font: 'Montserrat', sans-serif — Applied to all main titles, headers, and section names for a bold, professional look.
  • Body Font: 'Roboto', sans-serif — Applied to paragraphs, lists, and general body text to guarantee maximum readability.
